# 拾页开发计划

## 范围与约定

- 交付无需构建的纯 HTML、CSS、JavaScript 单页原型，可直接打开 `index.html`。
- 素材统一使用真实路径 `./asset/cover.png`、`./asset/paper.png`、`./asset/font.ttf`，同时提供 CSS 和字体兜底。
- 浏览器自动保存后合上，支持再次打开；Tauri 环境仅在保存成功且合上动画完成后关闭窗口。
- 用户已于本轮明确确认执行，包含需求实现、进度记录、测试和阶段提交。

## 小批次执行单元

1. 计划与进度：本计划、`doc/开发进度-10-19.md`（2 文件）。
2. 数据核心：`diary-core.js`、`tests/diary-core.test.cjs`（2 文件，worker 数据）。
3. 视觉：`styles.css`（1 文件，worker 视觉）。
4. 交互：`index.html`、`app.js`（2 文件，default）。
5. 集成验收：端到端用例与使用文档（每批不超过 3 文件，default）。

第 2、3、4 项接口固定后并行。explorer 只读核对需求和风险。所有提交由 default 统一执行，避免 Git 索引冲突。

## 状态与接口

- 状态顺序：closed → opening（约 800ms）→ flipping（约 1200ms）→ open → closing（约 800ms）→ closed。
- 翻阅前立即保存旧日期，防止 300ms 防抖跨日期写入。
- 存储接口：`saveDiary(date, data)`、`loadDiary(date)`，以本地 `YYYY-MM-DD` 为存储键；浏览器与 Node 共用核心。
- 保存失败保留编辑内容并提示重试，禁止以“已保存”掩盖失败；损坏数据不自动覆盖。
- 非交互皮革边缘设置 `data-tauri-drag-region`，文本框和按钮不成为拖动区域。

## 验收标准

- 合上初态、开封面、三页连翻、双页编辑、合上保存、再次打开完整闭环。
- 月历周一起始，历史圆点、跨月跨年、闰年、前后一天、回到今天正确。
- 晴阴雨雪切换、300ms 防抖、关闭前即时保存、刷新恢复正确。
- 中文输入法合成期间不提前保存；快速切日期不串写；存储异常清晰可恢复。
- body 透明，素材缺失仍可用，横线与行高对齐，窄屏和减少动态效果可用。
- Tauri v1/v2 关闭接口检测与调用时序经模拟验证；浏览器不调用关闭窗口 API。
- Node 单测及浏览器集成用例均有超时限制，单次测试不超过 60 秒。
